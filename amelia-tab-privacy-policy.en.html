Amelia Tab — Privacy Policy

Last updated: 16 October 2026

This policy explains what data the Amelia Tab browser extension processes, for what purpose and where it is sent. The information notice under Turkish Personal Data Protection Law No. 6698 (KVKK) is a separate document: KVKK Aydınlatma Metni (Turkish). The Turkish version is the original text; if the two differ, the Turkish version prevails.

1. Data controller

  • Data controller: Umut İlyas
  • Contact: fatal.iv@protonmail.com

2. Summary

  • Notes, tasks, reminders, countdowns, settings and chat history are stored only in the user's own browser. They are not sent to the developer or to any server.
  • The extension has no accounts, sign-up or user profiles. No advertising, analytics or tracking tools are used.
  • Some features send data only when the user uses that feature. The data goes first to Amelia Tab's own service server and from there to the service that provides the feature. The developer does not view or personally review it.
  • Data is not sold and is not used for advertising.

About the IP address

To prevent abuse and quota overruns, the service server limits the number of requests per IP address. These counter records are short-lived (between 5 minutes and 1 hour) and are deleted when they expire. The hosting provider may keep additional technical logs under its own terms. The service server does not record the content of chat messages or API keys.

Data that stays on the device

Notes, task lists, countdowns, reminders, settings, chat history, Pomodoro statistics and shortcuts are kept in the user's browser and are deleted when the extension is removed. The "frequently visited" list is read from the browser's own data and is not sent anywhere.

Media widget (optional)

If the media widget is enabled, the extension reads the title, artist and playback state of media playing in open tabs only on the user's device. This information is not sent anywhere and is not stored. The permission can be revoked at any time from the browser settings or the extension.

5. Recipients and transfers abroad

Depending on the feature used, data may be passed to the following groups of recipients:

  • Hosting and infrastructure providers: the cloud infrastructure provider hosting the Amelia Tab service server.
  • Services providing the feature: weather (OpenWeatherMap), background photos (Unsplash), white noise (Freesound) and site icons (Google).
  • AI providers: Anthropic, OpenAI, Google (Gemini) and DeepSeek. Data is passed only to the provider the user selects; DeepSeek is a China-based provider.

Because these services' servers are located abroad, using the relevant feature involves a transfer of data abroad.

  • The user chooses the AI provider and sends the message; selecting a provider and sending a message is treated as the user's choice to have the data passed to that provider.
  • AI chat content is subject to the selected provider's own privacy policy. Sharing sensitive or personal information in chat is not recommended.
  • Data is not sold, not used for advertising and not shared for purposes such as credit or scoring.

6. Retention

  • Data on the device: until deleted by the user or until the extension is removed.
  • AI key: until deleted by the user. It can be deleted individually or entirely at any time under Settings > AI.
  • IP-based request counters: at most 1 hour.
  • Chat content is not stored on the service server.

7. Security

Communication with the service server uses an encrypted connection. AI keys are stored encrypted on the server, and the encryption key is kept in a separate protected place rather than in the software itself. AI requests are accepted only from the extension itself.

8. Chrome Web Store "Limited Use" statement

Amelia Tab's use and transfer of user data to any other app complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide user-facing features; it is not transferred or sold for advertising, data brokerage or credit assessment.

9. Changes

When this text changes, the "Last updated" date is renewed. Significant changes are announced inside the extension. Earlier versions can be reviewed in the change history.
